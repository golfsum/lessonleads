# LessonLeads design direction

Updated: 2026-08-25

The supplied screenshot is the high-fidelity desktop style and composition target. The pasted brief remains authoritative for behavior and truthfulness. Unverified logos, endorsements, testimonial copy, and customer statistics are excluded.

## Visual system

- Warm ivory canvas with white surfaces and deep forest-green ink
- Editorial serif display type paired with a compact neutral sans serif
- Restrained action green used for buttons, selection, progress, and key outcomes
- Modest 8 to 16 pixel radii, thin warm borders, and broad quiet shadows
- Dense, confident product layouts with little decorative whitespace
- Original golden-hour golf photography with no visible equipment brands
- Product proof uses the actual finder and actual dashboard states

## Responsive behavior

- Desktop uses a layered hero with copy, photography, and the interactive finder
- Tablet stacks the result state under the finder when needed
- Phone layout is one column, uses 16 to 20 pixel padding, 44 pixel targets, and replaces the question with the result
- Dashboard information reflows into readable cards instead of shrinking a desktop screenshot
- Selection is shown with border, fill, icon treatment, and text state, not green alone

## Copy rules

Use direct golf-instructor language. Never imply a booking-system integration when LessonLeads only redirects to a coach-provided URL. Never use fabricated social proof, usage counts, or completion times.
